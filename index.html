حفظ نسخة للشير بضمان عدم تعارض الكاش، أو نسخة آمنة للمشرفين بدون تكلفة، أو نسخة جاهزة لفرع آخر

1. 💾 حفظ نسخة الفرع الكاملة للشير (.html)

تحفظ كل بيانات الفرع وسجلات Mini-ERP مع رقم إصدار جديد (data_version) بحيث أول ما أي موظف يفتحها من الشير تُحدّث عنده فوراً بدون كاش قديم.

2. 🔒 تصدير نسخة الشير للمشرفين (بدون أسعار تكلفة نهائياً)

تُصفّر أسعار التكلفة وقيم المخزون تماماً من الكود، وتُزيل كلمات مرور المدير وأزرار الرفع — آمنة 100% للوضع على فولدر الشير بصلاحية قراءة فقط (Read-Only).

3. 🏢 تجهيز نسخة مفرّغة لإرسالها لفرع آخر (.html)

تحتفظ بالشجرة السلعية والمستهلكات الثابتة وتُفرّغ الأرصدة والمبيعات؛ وبمجرد أن يرفع الفرع الآخر ملفاته يتعرف البرنامج على اسمه تلقائياً.

4. ⚡ تبادل البيانات السريع (Backup / Sync JSON)

📘 دليل التشغيل وخطوات العمل اليومية — منظومة هايبر موسى V26 Cloud

مرجع سريع لكل موظف ومدير فرع: تشغيل الشير، رفع الملفات، كاميرا الموبايل، والروتين اليومي

1. تشغيل سيرفر الفرع على أي ويندوز (7 / 8 / 10 / 11 بدون Python)

  1. فك ضغط حزمة HyperMousa_V26_BranchServer.zip في مجلد ثابت على جهاز مدير الفرع (مثل C:\HyperMousa_V26).
  2. اضغط مرتين على ملف Start_HyperMousa.bat — يعمل فوراً بـ PowerShell المدمج في ويندوز ويعرض لك رابط الشبكة الداخلية مثل http://192.168.1.50:8080.
  3. عند ظهور رسالة جدار الحماية (Windows Firewall) لأول مرة، اضغط Allow Access ليفتح الرابط من كل أجهزة الفرع وموبايلات الواي فاي.
  4. لتفعيل الكاميرا الحية على موبايل أندرويد بـ Chrome عبر رابط HTTP: افتح في كروم الموبايل chrome://flags/#unsafely-treat-insecure-origin-as-secure ← فعّل الخيار (Enabled) ← اكتب رابط الـ IP مثل http://192.168.1.50:8080 ← أعد تشغيل كروم. (أو استخدم زر «📸 التقاط صورة باركود» مباشرة بدون أي إعدادات!).

2. ما هي الملفات التي تُرفع ودور كل ملف؟

📘 دليل الأصناف (أسبوعياً): يوحّد الباركودات تحت كود الصنف الصغير ويمنع التكرار.
📦 رصيد الفرع الأساسي (يومياً): يحدّث الأرصدة والمستهلكات، ويتعرف على اسم الفرع تلقائياً، ويحفظ لقطة الأمس لكشف السالب الجديد.
🏢 أرصدة الفروع الشقيقة (يومياً): تقارن عجز فرعك بفائض الفرعين الآخرين لتجهيز أذون التحويل.
📈 مبيعات 60 يوم (يومياً/مرتين أسبوعياً): تحسب كفاية الأيام وتصنّف قوة وضعف الأصناف (ABC) وخطر إعدام الصلاحيات.
🚚 أوامر التوريد + التوريد المستلم (يومياً): تربط أوامر الشراء بالاستلام الفعلي لكشف الشركات المتأخرة والمعلقة.
🏷️ ملف المجلة والعروض (مع كل مجلة): يكشف فوراً أي صنف عرض رصيده صفر أو سالب.

3. خطوات العمل اليومية (لمدير الفرع ولموظف الصلاحيات)

مدير الفرع (10 دقائق صباحاً): ارفع الرصيد والتوريد المستلم ← راجع «شريط تقرير الصباح» في الأعلى ← وجّه مهام فحص للأرصدة السالبة الجديدة ← راجع الصلاحيات الحرجة (≤ 15 يوم) واتخذ قرار (خصم / مرتجع / تحويل) ← غطِّ نواقص فئة A بالتحويلات ثم أوامر التوريد.

موظف الصلاحيات (من الموبايل): افتح رابط الـ IP ← ادخل على تبويب «⏳ تواريخ الصلاحية» ← امسح الباركود بالكاميرا ← اكتب تاريخ الانتهاء والكمية واسمك واضغط «حفظ واعتماد» (بعد الحفظ يُقفل السجل تلقائياً ولا يعدّله إلا المدير).

⚙️ ضبط مسار قاعدة البيانات على الشير

حدد مسار المجلد المشترك (مثل \SERVER\HyperMousa\Data أو Z:\HyperMousa\Data) ليتم حفظ قاعدة البيانات والنسخ الاحتياطية اليومية فيه تلقائياً.

🛡️ يتم إنشاء نسخة احتياطية يومية تلقائياً داخل مجلد Backups بجانب قاعدة البيانات للحفاظ على بياناتك لسنوات.
